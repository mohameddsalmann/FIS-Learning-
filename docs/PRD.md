# Product requirements

## Problem and users

Students need a place to turn course notes into explanations, evidence, practice, and a revision plan. FIS serves independent students working from PDFs, students preparing for exams, and bilingual learners who prefer English or Arabic. A reviewer can try the published learning flow from a prepared optics lesson without creating an account.

## Primary journey

1. Choose **Study a document** from Home. A learner can also start a course without a PDF or explore the optional pre-authored lesson.
2. Select a PDF, then upload to a new or existing course in a private guest workspace.
3. Watch upload and indexing advance automatically in the course workspace. Resume saved work after reopening the course, or retry a paused or failed step.
4. Ask the tutor a question in course context. Follow a citation to the original page.
5. Start a Quick Quiz with three mixed questions, or expand the options to choose topic, difficulty, type, and count. Save the attempt and revisit weaker topics from Progress.
6. Open Help to restart the optional tour or check off activities recorded from actual study actions.
6. Resume saved tutor conversations under History. Create an account to keep the guest workspace, or export or delete it in Settings.

## Product decisions

- Start the default experience in automatic routing. Put model, temperature, response length and session-only personal key in Advanced Settings.
- Show private-course progress from actual activity and attempts. Label prepared sample results as stored in this browser. Avoid claims of validated mastery.
- Keep a source view adjacent to the learning job. Use clear prompts and offer a recovery action when extraction or inference is unavailable.
- Show whether the tutor has course evidence and distinguish source-supported explanation from provider availability. Image and video appear as tutor inputs. Voice supports editable browser dictation and optional model playback.
- Make the prepared optics course fail independently of remote dependencies and give it clearly attributed lesson sections and deterministic questions.

## Acceptance and scope

The student can complete the sample journey unauthenticated, open a citation, receive practice feedback, and find the result again after refreshing. With services configured, the student can create a course, process a text PDF, receive a source-grounded reply, and save a practice attempt. The user can complete these tasks at mobile and desktop widths with English or Arabic selected. Scanned PDFs show an OCR-required status. Shared courses, institutional administration, academic certification, and automatic OCR are outside the current release.

# Portfolio case study

FIS started as a bilingual study chatbot with browser-local chat history and specialized media tools. The current design keeps the supplied FIS mark in a monochrome palette and makes the student's PDF the main entry point. The workspace connects tutor responses with private sources, quizzes, history and measured progress. Review the [design comparison and research](design/design-research.md).

Two directions were considered. An editorial course-first workspace emphasizes the active course and evidence, with a distinct feeling of place and helpful document navigation. A dense course console favors frequent switching with more information visible at once and makes the first lesson busier on narrow screens. The course-first direction was selected to make the prepared lesson and private study entry easy to find.

- YouMind prompt composer informed a contained input and contextual controls. The reference was visually inspected. [The UI Index](https://theuiindex.com/elements/579fbcbd-da84-46e4-8c88-41762556bd31/prompt-composer-what-would-you-like-to-learn-or-create-input-youmind)
- Superr informed editorial content hierarchy and comfortable spacing. The reference was visually inspected. [Lapa Ninja](https://www.lapa.ninja/post/superr/)
- Class and lesson detail informed the research direction for topic/material navigation. The gallery was documented as text-only evidence. [Pixlpin](https://pixlpin.com/screens/class-and-lesson-detail)
- Duolingo informed exploration of short practice and feedback loops. The gallery was documented as text-only evidence. [Banani UI References](https://www.banani.co/references/apps/duolingo)

A reviewer can open the prepared optics lesson, ask a question, inspect the lesson section cited by the result, complete a mini quiz, and see stored feedback. Engineering provides actual implementation and fixture metrics. The earlier product and software handbook is the migration baseline. Hosted measurements and real provider generation remain separately tracked release gates.

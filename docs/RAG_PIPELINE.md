# Source-grounded learning

1. Receive a PDF into private storage under the learner's owned course. Server multipart handles up to 4 MiB and direct-to-Blob handles larger PDFs up to 20 MiB. An authenticated PDF viewer preserves the original page.
2. Extract the PDF title when available and the text of each physical page with PDF.js. The extractor keeps reading order as reported by PDF.js. Line geometry preserves paragraph gaps and separates widely spaced cells on the same baseline with pipes. Scans without a selectable text layer receive an OCR-required outcome. Limits include 150 pages, 36,000 extracted characters per page, and 600 chunks.
3. Normalize and index page-bounded chunks. Version 2 keeps line breaks, prefers a line boundary when splitting within the latter part of a 950-code-point window, and retains up to 120 code points of overlap. SHA-256 over whitespace-normalized content removes identical chunks while retaining the first page reference. Duplicate uploads can remain individually available in the viewer. Retrieval returns one excerpt per identical content hash. Version 1 page windows remain searchable alongside new version 2 rows.
4. Continue ingestion through persisted checkpoints. Completed batches reuse saved vectors. A repeat upload in the same owned course can adopt a saved embedding model and dimension when every chunk in its version already has a matching vector. After indexing, derive and save a study outline with headings, topics, definitions, examples and page references. Course starters rank concepts, comparable measurements and study checks from the saved evidence. Opening an older course can refresh its starters from the saved outline. This step uses deterministic text extraction and consumes no generation quota.
5. Verify the learner owns the course. Search only ready document chunks. PostgreSQL full-text retrieval uses the existing GIN-indexed simple search vector. It tokenizes English and Arabic, removes question filler, handles common variants and inflections, and accepts partial vocabulary matches. When lexical search is the only signal for a longer question, the best candidate passages must cover at least 40% of its distinctive terms.
6. Run one query embedding in the largest available model-and-dimension space. Compare only compatible vectors. The 2,048-dimensional query uses the existing pgvector half-vector distance and index. Other dimensions use pgvector cosine distance. A compatible model that fails can fall back to lexical evidence when available. Documents in other spaces remain eligible for keyword search.
7. Fuse the independent rankings with Reciprocal Rank Fusion and cap candidate input. The live tutor uses those fused rankings. The controlled retrieval evaluator can opt into reranking when six or more distinct candidates exist and the two lists disagree at rank one. Fused rankings remain usable if the evaluation reranker fails. Append at most one same-page or topically relevant adjacent-page chunk. Tutor context is capped at six excerpts and an estimated budget of 2,400 tokens.
8. Send source excerpts to the tutor as untrusted data. Course questions with zero evidence return a localized no-sources response. The tutor is instructed to identify missing support when results are merely related. The server resolves citation labels against the retrieved chunks before saving a turn. The authenticated viewer verifies ownership again when resolving a citation or opening the PDF.

PDF.js reading order, font coverage, multi-column layouts, merged cells and OCR limit the extracted structure. The original PDF remains the reference for complex layouts. Cross-language matching depends principally on the compatible multilingual embedding model. Sparse-only retrieval handles same-language terms and shared words, and its Arabic normalization does not translate documents.

The prepared optics course has a separate deterministic search and quiz bank. It remains available without AI inference and identifies its prepared content. The controlled database runs and hosted evidence have separate scopes. [AI evaluation](AI_EVALUATION.md).

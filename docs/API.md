# API contracts

All paths below are relative to the same site. Private endpoints use Better Auth cookies. Resource IDs are opaque. Owner checks apply to the primary resource and child lookups. Validation errors use 400, unauthenticated access uses 401, unavailable resources use 404, bounded uploads use 413/422, and quotas or unavailable services can use 429/503. Treat client-facing failures as retry guidance. Never log request bodies or credentials.

## Workspace and documents

- `GET /api/workspace/dashboard` returns courses, progress, conversations, recent quiz attempts, revision and completed sessions. `practiceTotals` aggregates saved attempts, graded answers, and distinct practiced topics across the workspace. `completedTutorSessions` and `hasUploadedDocument` support the onboarding checklist. `GET|POST /api/workspace/courses` lists or creates courses. Creation input includes `title`, optional `description`, and optional `firstTopic`.
- `GET|PATCH|DELETE /api/workspace/courses/:id` reads, edits or removes a course. `POST /api/workspace/courses/:id/topics` accepts `title`.
- `GET|DELETE /api/workspace/conversations/:id` reads or removes a conversation. `GET /api/workspace/quizzes/:id` returns a quiz without answer keys.
- `POST /api/workspace/quizzes/:id/attempts` takes `answers` containing `questionId` and `answer`, with an optional UUID `submissionKey`. Response includes saved feedback and attempt data. Each feedback entry resolves still-available sources to owned document, page and citation identifiers. `PATCH /api/workspace/revision/:id` takes `completed`.
- `GET /api/workspace/export` returns a private JSON attachment. `DELETE /api/workspace/account` accepts `confirmation` equal to `DELETE`.
- The browser first reserves a document with `POST /api/documents/uploads`, passing `courseId`, `name`, and `sizeBytes`. For PDFs up to 4 MiB, `POST /api/documents` accepts multipart `file`, `courseId`, and optional `uploadId`. The smaller upload endpoint still accepts the legacy request without `uploadId`. PDFs above 4 MiB through 20 MiB use the `/uploads/token` Blob client exchange and `POST /api/documents/:id/finalize`.
- `GET /api/documents/uploads/:id` reads an owned upload reservation and `DELETE /api/documents/uploads/:id` discards an incomplete upload. `GET /api/documents/:id` reads file metadata and job state. `POST /api/documents/:id/process` advances bounded checkpoints and can return 409 with a retry window when another request holds the lease. `READY` records include the reusable learning outline when indexed by the current pipeline.
- `GET /api/documents/:id/file` streams the original. `GET /api/documents/:id/chunks/:chunkId` returns the excerpt and page for a ready document. `DELETE /api/documents/:id` removes the owned file and database record.

## AI and authentication

- `GET /api/learning/models` returns eligible models, overall status and per-provider status. Model metadata includes the upstream vendor and `gateway` that can fulfill the request. Only server-side model selection authorizes inference.
- `POST /api/learning/chat` accepts JSON or multipart with JSON `chat` and up to five `attachment` parts within the combined size limit. Chat options include `courseId`, `conversationId`, `mode`, `model`, `temperature` and `maxTokens`. Modes include `auto`, `quick`, `detailed`, `steps`, `examples`, `visual`, `socratic` and `exam`, with compatible follow-up modes. The SSE response returns `content`, then validated citations and the persisted conversation ID. Current citations include the response-local `label` in addition to the permanent chunk ID. The final metadata may include the normalized `answer` to replace streamed content. Clients must handle streamed failures after an HTTP 200. A course request without supported excerpts or attachments returns 422 before answer generation.
- Contextual actions can reuse sources from the latest saved reply after checking the conversation, course, reply text, and current source availability. If the cited excerpt contains exact, consistently formatted measurements with a shared unit, Explain visually can build the chart locally and persist it without a model ID. Other visual requests use validated model blocks with the original-page excerpt as a fallback when available.
- `POST /api/learning/quiz-generation` accepts quiz settings and course or conversation context, and returns a safe question projection. The `speech`, `image`, `decision` and `notes` handlers expose specialist workflows. Inspect the corresponding route schemas for exact specialist payloads.
- The `/api/auth/*` catch-all delegates to Better Auth. Anonymous sign-in, account creation and normal sign-in are bound to the application origin. AI routes can accept `x-fis-openrouter-key` from an active session. This credential changes token choice, while capability, quota and free eligibility rules still apply.
